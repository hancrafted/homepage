## Disciplines

- **Prior art**
  - When the question is about shape rather than content, find the published spec and adopt it whole. Route new content into a document that already exists before creating one that does not.

- **Last responsible moment**
  - Ask whether a real run is behind the decision, not whether you know the answer. If nothing is blocked, record the deferral against the event that reopens it — never against a date.

- **Audience design**
  - Name who reads the artefact before shaping it, then walk one real use end to end in their seat. Most structural arguments dissolve once the reader is named.

- **Single Writer Principle**
  - Read widely, write to exactly one location. Where a run finds something missing outside its write scope, report it and hand back rather than fixing it in passing.

- **API-first**
  - Settle the verbs, the arguments and the shape of what comes back before deciding where anything runs. Surface constrains plumbing far more than plumbing constrains surface, so reorder the question if it arrived the other way round.
